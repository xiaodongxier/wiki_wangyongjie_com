第一章

WorkBuddy 是什么

1.1 一句话定位

WorkBuddy 是腾讯出品的全场景 AI 办公工作台。说出要求、开始执行任务、交付完整成果，并完美连接腾讯办公生态。

1.2 它和普通 AI 聊天的核心区别

这是最该讲清楚的一点，直接决定了它对你有没有用。

普通 AI 对话WorkBuddy
只能对话，提供建议能够实际执行任务，直接产出文件 / 结果
需要你手动操作文件自动操作你授权的本地文件与系统
适合单步骤简单任务胜任多步骤、跨工具的复杂任务
输出一段文字回复交付可验收的成品（文档 / 图表 / 网页 / 视频…）

← 表格可左右滑动查看 →

1.3 三种工作模式，对应三种干活姿态

问一问 Ask

只聊不动

仅问答与信息查看，不修改任何文件。适合了解内容、确认需求。

做一做 Craft

你只管说，我直接干

直接执行任务并修改文件。适合文档生成、表格处理、文件整理。

想一想 Plan

先想后做

先生成执行计划，确认后再操作。适合多步骤、需审阅改动范围的任务。

✅
怎么选？官方建议首次使用优先选 Ask，熟悉后再按任务复杂度切到 Plan 或 Craft。模式在对话框里随时可切换，具体位置见 第六章 界面面板速览。

第三章

真实使用场景（按你要做的事）

下面按常见场景给出“你可以直接这样说”的示例。点右上角复制，改成你自己的事，就能马上用。

  • 帮我把这段会议录音的文字稿整理成纪要，按“结论 / 待办 / 负责人 / 截止时间”输出表格。
  • 把这一周的零散记录汇总成一份周报，语气正式一点，控制在 800 字内。
  • 这 30 张照片按“日期-主题”规则批量重命名，并归类到一个新文件夹。
  • 把这份报名表按城市统计人数，画一张柱状图，并标出人数最多的三个城市。
  • 调研竞品 A 和 B 的定价策略，给我一张对比表和三条建议，标注信息来源。
  • 为新产品写一版小红书风格的种草文案，再配一张主视觉海报图。
  • 把这页需求描述做成一个可点击的落地页原型，手机上也要好看。
  • 把这份用户反馈 Excel 做情感分类，汇总出 Top 5 抱怨点和改进建议。
  • 读这个仓库的登录模块，帮我找潜在的安全问题并给出修复方案。
  • 用这份销售数据画一个月度趋势图，红色代表上涨、绿色代表下跌。
  • 写个 Python 脚本，把这个 CSV 按城市拆成多个文件，并附一份使用说明。
  • 帮我看看这段报错日志是什么原因，给出定位步骤和最小复现方式。
  • 帮我写一封委婉拒绝合作的邮件，语气客气但态度明确。
  • 把这篇长文总结成 3 条要点，再改写成适合发朋友圈的口语版本。
  • 每天早上 9 点给我一份所在行业的简报，控制在 5 条以内。
  • 把这份 PDF 里的表格提取出来，整理成一个干净的 Excel。
💡
提示：说“做什么”时，最好带上“给谁看、什么格式、有什么约束”。信息越具体，结果越省心。

第五章

安装 WorkBuddy（实操图解）

下面把 Windows 和 Mac 的安装过程拆成一步一步，每步都配了官方截图。对照着做，3 分钟就能装好。

💻
环境要求：Windows 10 及以上。Windows 7/8/8.1 将无法启动 WorkBuddy。

一、下载安装包

  1. 访问官网，点击“立即下载”

    打开 WorkBuddy 官网，找到下载按钮并点击，等待安装包下载完成。

    官网首页的“立即下载”按钮
  2. 启动安装程序

    双击已下载的安装包，打开安装向导。

  3. 同意许可协议

    勾选“我同意此协议”，然后点击“下一步”。

  4. 选择安装路径

    默认路径即可；如需修改，点击“浏览”后选择位置，再点“下一步”。

  5. 确认开始菜单文件夹

    保持默认文件夹名称，点击“下一步”。

  6. 创建桌面快捷方式

    建议勾选“创建桌面快捷方式”，方便后续打开，然后点击“下一步”。

  7. 开始安装

    确认配置无误后，点击“安装”按钮，等待进度条完成。

  8. 完成安装

    安装完成后点击“完成”，退出安装向导。

二、登录与基础设置

  1. 启动并登录

    打开 WorkBuddy 客户端，点击“登录”按钮。

  2. 微信扫码登录

    勾选《服务条款》与《隐私协议》，使用微信扫码完成登录。

  3. 切换界面语言

    登录成功后，点击左下角“头像”→“语言”即可切换界面语言。

  4. 检查更新

    点击左下角“头像”→“检查更新”，系统会自动检测并升级到最新版本。

一、下载安装包

  1. 访问官网，选择对应版本

    在浏览器弹窗中允许下载，等待安装包下载完成。

    双击已下载的 .dmg 磁盘映像文件，打开安装窗口。

  2. 拖入 Applications

    将 WorkBuddy 图标拖到 Applications 文件夹中，松开鼠标等待拷贝。

  3. 等待拷贝完成
  4. 推出磁盘映像

    拷贝完成后，推出已挂载的 WorkBuddy 磁盘映像；如不再需要，可删除 .dmg 安装包。

6.3 设置工作空间：告诉它去哪读、往哪存

使用前建议先设置工作空间。WorkBuddy 会在这个空间里读取和保存文件，没指定路径的任务也会优先在这里执行。

📁
什么是文件路径？就是文件夹在电脑里的位置。
Windows：C:\Users\你的用户名\Desktop\工作资料
Mac：/Users/你的用户名/Desktop/工作资料
不用手动输入——设置时在文件选择器里点选目标文件夹就行。若没提前指定，WorkBuddy 会自动创建独立空间。
💡
怎么选工作空间？建议按任务类型分别建空间，比如「发票整理」「周报」「待处理照片」，既好管理，也能降低误操作风险。

6.4 选择技能：装一个技能，多一种本事

技能（Skills）用来扩展 WorkBuddy 的任务能力。启用后，它就能完成更多特定类型的工作。

在对话框中选择已安装的技能，执行任务时会自动调用对应能力：

技能示例效果
PPT 制作根据资料或数据生成演示文稿
海报生成根据需求生成活动海报
自动化报表合并多份 Excel 并输出图表报告

WorkBuddy 内置 20+ 技能包，覆盖文档处理、数据报表、海报设计、文件整理等场景，也支持用自然语言创建自定义技能。

6.5 连接第三方应用

在这里快捷管理连接器，接上外部服务后，WorkBuddy 就能直接读写这些系统的数据，少复制、少粘贴。

6.6 权限管理：控制它能自己做多少

🔒默认权限

涉及敏感操作时（如修改文件、在工作空间外执行），需要你确认后才继续。

🔓完全访问权限

减少确认步骤，允许直接执行更多操作。仅建议在你信任当前任务时使用。

6.7 新建任务：一个任务 = 一个独立空间

每个对话对应一个独立任务，任务之间互不影响，各自维护独立的工作空间与上下文。

  1. 在主界面点击新建任务（若未提前指定目录，系统会自动创建独立工作目录）；
  2. 输入任务内容、选择工作目录与模型后发送，即可开始执行。
🔀
执行中的任务显示在左侧边栏，可随时切换查看进度。WorkBuddy 支持多任务并行处理——一个在跑数据出图，另一个可以同时写文档。

6.8 右侧边栏：预览文件、看产物、追踪改动

右侧边栏是 WorkBuddy 的核心工作面板，集文件预览编辑、产物管理、变更追踪和网页预览于一体。任务产生对话后，从右上角展开它，就能在同一界面完成阅读、编辑与核对。

第七章

进阶技巧

7.1 专家中心：遇到专业问题，找专家聊

左侧「专家」里按分类浏览 100+ 领域专家（法律、金融、医疗、编程等）；点开即可发起专业对话，比通用聊天更准、更对口。

7.2 自动化：让 AI 定时帮你干活

在任务里描述“每隔 / 每天 / 每周几 做什么”，即可创建定时任务。典型用法：每日行业简报、每周数据巡检、到期提醒；也可以设置“某天某点提醒我”的一次性任务。

7.3 连接器：把你常用的服务接进来

在设置中信任并启用连接器（如腾讯文档、邮箱、网盘、地图、代码托管等）。接上之后，WorkBuddy 能直接读写这些服务里的数据，少复制、少粘贴。

7.4 技能市场：装一个技能，多一种本事

技能是可安装的“能力包”，覆盖办公、研发、设计等场景。需要时一句话安装，AI 会自动按技能里的标准流程执行。

7.5 提示词（Prompt）黄金法则

①说清目标

你要什么、给谁用、什么格式。

②给足上下文

贴上数据、文件、参考样例。

③定边界

范围、禁忌、风格、长度。

④会追问

结果不对就接着改，越聊越懂你。

⚡
三个提效小习惯：① 把参考文件直接拖进对话，比复制文字更完整；② 一次只说清一个目标，复杂任务交给 Plan 模式拆；③ 满意的说法存进备忘，下次改几个词就能复用。

第十章

常见问题 FAQ

不懂技术也能用吗？
能。它是自然语言驱动的，不用写代码，照着手册里的例子说就行。说不清楚也没关系，它会追问你。
WorkBuddy 会乱动我的文件吗？
只在你授权并下达任务的范围内操作；Ask 模式完全只读，不会改动任何文件。涉及删除等风险操作时会先提示并等你确认。
我的文件和隐私安全吗？
它只读写你指定的工作空间目录，没授权的文件夹碰不到；默认权限下，涉及删除、外发等敏感动作会先弹出确认。身份证、账号密码这类私密材料，建议不要放进工作空间。
和 ChatGPT / 普通大模型有什么区别？
它不是只聊天，而是能调用工具、操作文件、交付成品的“执行型”工作台。区别详见第一章的对比表。
结果不满意怎么办？
直接追问改。告诉它哪里不对、想要什么效果，它会在原结果上继续修改，不用从头重来。
任务卡住了怎么办？
换种说法重试、补充上下文，或切换到 Plan 模式让它先出方案；也可以直接在对话里问它“刚才为什么没成功”。
它能连我常用的其他软件吗？
可以。在设置里启用并信任对应连接器（腾讯文档、邮箱、网盘、地图、代码托管等），之后就能直接读写这些服务里的数据，不用来回导出导入。
登录要用什么账号？
打开客户端后点「登录」，用微信扫码即可，不需要单独注册账号。扫码步骤见 第五章 安装 WorkBuddy。
