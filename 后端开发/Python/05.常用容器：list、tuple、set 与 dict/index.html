    常用容器：list、tuple、set 与 dict

    容器 特性 适合场景
    list 有序、可变、可重复 一组需要按顺序处理的数据
    tuple 有序、不可变 固定结构的记录或不可变配置
    set 无重复、无索引顺序保证 去重、成员判断
    dict 键到值的映射 结构化记录、按键查找 
    names = ["Alice", "Bob"]
point = (10, 20)
tags = {"python", "backend"}
user = {"id": 1, "name": "Alice"}

    字典读取未知键时，mapping["key"] 会抛出 KeyError；可选字段用 get：

    nickname = user.get("nickname", "")

    set 和 dict 的键必须可哈希，通常意味着不可变。例如 str、int、tuple（其元素也可哈希）可以做键；list 和 dict 不可以。

    不要依赖 set 的遍历顺序。需要稳定输出时排序，或明确使用 list 保存顺序。
